Oven is a backend framework for Bun. It replaces Express, takes its cues from FastAPI, and is
TypeScript-native end to end.

The promise: **you should never wire infrastructure by hand again.** Auth, a database, file
storage, email and background jobs are configuration, not a week of plumbing.

## Where to start

- **[Philosophy](/docs/start/philosophy/)** — why Oven makes the choices it makes.
- **[Tutorial](/docs/tutorial/first-route/)** — build up from your first route.

## Status

Pre-alpha. The core is built and tested — router, server, context, errors, response coercion
and graceful shutdown. Validation, auth, database, storage, mail and queues are next; see the
[roadmap](https://github.com/hiteshchoudhary/theoven/blob/main/TODO.md).

Pages describing features that do not exist yet say so at the top. We would rather tell you
than have you copy code that cannot run.
